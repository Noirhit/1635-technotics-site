1635 TECHNOTICS WORDPRESS THEME

This is the WordPress version of the Team 1635 static site.

Install:
1. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
2. Upload technotics.zip and activate it.
3. Create pages with these slugs: about, robot, blog, sponsors, contact.
4. Create a page called Home and set it as the static homepage in Settings > Reading.
5. Set the Blog/Logbook page as the Posts page in Settings > Reading.
6. Create a menu under Appearance > Menus and assign it to Primary navigation.
7. Set the site images under Appearance > Customize > Technotics images.
8. Add blog posts under Posts > Add New. Add a Featured Image to each post.

The contact form uses the existing Web3Forms key. Add blog.team1635.org to the
allowed domains in Web3Forms before testing the form on this WordPress site.
